# Font sources used for the documentation previews

The renderer reads the installed M5GFX 0.2.28 font headers:

- `src/lgfx/Fonts/glcdfont.h` (Font0 / classic Adafruit bitmap font).
- `src/lgfx/Fonts/GFXFF/FreeSans24pt7b.h` (the same month-label font selected by the firmware).

Font headers and compiled renderer binaries are not redistributed in this repository.
