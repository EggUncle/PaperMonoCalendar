## 本次本地验证

环境：macOS，Arduino CLI 1.4.1，M5Stack ESP32 3.3.9，M5Unified 0.2.21，M5GFX 0.2.28，M5PM1 1.0.7，M5IOE1 1.0.9。

- 新的独立构建脚本编译通过：Flash 888,623 / 3,145,728 字节（28%）；全局内存 33,040 / 327,680 字节（10%）。这是应用分区和静态 RAM 指标，不是整片 Flash/PSRAM 的占用。
- 本机使用已安装的固定版本依赖；全新 Linux 环境的下载/编译由新增 GitHub Actions 检查，以实际运行结果为准。
- 合成包测试直接抽取并编译固件现有纯解码函数，而非只测试一份 Python 复刻实现；测试不会接触硬件或本机活动。
- 覆盖 v2/v3 的 1–112 天、CRC 标准向量、所有截断长度、逐字节单 bit 损坏、包版本/星期/日期/时钟边界，以及仅时钟改变不触发 activity dirty 的比较语义。
- Shell 语法和 CLI 缺失提示已测试。

重编译包含 `__DATE__` / `__TIME__`，因此不同时间的二进制哈希和大小可能不同，即使功能源码未变。产物只保存在忽略的 `build/`，没有上传设备固件镜像。
